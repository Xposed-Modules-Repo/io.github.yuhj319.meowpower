小米安全中心的策略偏保守，与部分使用习惯有冲突。**这个模块把 23 项策略的开关交到你手上。**

**能调什么**

**充电保护**：夜充保护、通用保护、pogo 底座、无线静音、快充、旁路充电、健康度伪装、限制百分比

**性能与电源**：电源模式切换、超省电、降频降亮度、温控降频

**后台与权限**：AppOps 私有限制、一键清理、自启动

**网络**：联网、后台联网、流量停网、热点

**安装**：签名校验

**它怎么做的**

**API**：libxposed API 102（现代 Xposed API），非 legacy XposedBridge。

**定位**：拦截点从 dex 逆向逐项定位，读实现体确认语义后写代码。例如安全中心的 AppOps 封装形参顺序与标准 API 不同，照抄标准顺序会静默失效。

**生效**：配置走 RemotePreferences，改完即时生效，无需重启目标应用。

**持久化**（可选）：用 root 把策略写进系统属性与 Settings，应用前自动备份，可还原。

**界面**：Kotlin + Compose + Miuix，底部导航 + 滑动切换，每项带可展开详情。

**怎么用**

1、安装 APK，LSPosed 中启用模块

2、**作用域勾选「安全服务」**（com.miui.securitycenter）

3、重启安全服务进程，或重启手机

4、打开模块，首页显示「工作中」，按需开启

**注意**

**需要 LSPosed**，适配 Android 16 / 17

**首次使用建议只开「拦截保护入口」**，观察几天再逐步加其它功能

**「持久化落地」会写系统设置**，应用前自动备份，可一键还原

**安装前先卸载旧版本**（签名变更时无法覆盖安装）

模块仅修改本机行为，不涉及数据上传。**遇到问题欢迎评论区反馈**，带上机型与系统版本。
